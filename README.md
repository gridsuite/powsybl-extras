## Description

The **gridsuite-powsybl-extras** library provides extensions to [PowSyBl](https://github.com/powsybl) for the [GridSuite](https://github.com/gridsuite) project.

It is a **Java library** for sharing **domain interfaces, network extensions, and calculation result models** across GridSuite services and libraries. 
The library builds on PowSyBl's extension and provider mechanisms so that domain APIs can evolve independently of their implementations.
